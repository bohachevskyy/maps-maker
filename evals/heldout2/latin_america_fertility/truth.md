- URL/API: https://ourworldindata.org/grapher/children-born-per-woman.csv (Our World in Data Grapher CSV, 'Fertility rate: births per woman' = total fertility rate; Human Fertility Database / UN World Population Prospects 2024; the spec's slug `fertility-rate` now returns 404, `children-born-per-woman` serves the same series); latest non-missing year per country; geometry https://naturalearth.s3.amazonaws.com/10m_cultural/ne_10m_admin_0_countries.zip and the 1:10m map-units file (to colour French Guiana, Guadeloupe, Martinique separately).
- Vintage: OWID file downloaded 2026-10-27; every row is 2023 (50) (UN WPP 2024 estimates, no projections in the file).
- Licence: OWID data CC BY 4.0 (UN WPP: CC BY 3.0 IGO). Boundaries: Natural Earth 1:10m (public domain).
- Rows: 50 of the 52 members of UN M49 region 419 'Latin America and the Caribbean' (chosen by an explicit ISO3 list: Caribbean, Central America incl. Mexico, South America). No OWID value: BVT, SGS (uninhabited Bouvet Island and South Georgia). Columns: key (ISO3), name, value (children per woman), unit, year, subregion.
- Caveat: the list contains 17 dependencies (e.g. Puerto Rico, Guadeloupe, French Guiana, Aruba) that OWID reports with their own UN WPP estimate. Spec spot 'GTM>KOR': South Korea is not in the region, so it is unevaluable against this truth.csv; OWID's own value (2023) is KOR 0.72 against Guatemala 2.31, so it holds.
